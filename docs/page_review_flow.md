# 기능별 페이지와 검토조서

## 공통 흐름

검토 목적 안내 → 필요한 자료·조건 입력 → 입력·기준 확인 → 가능한 검사 수행 → 수행/미실행과 사유 표시 → 검토조서 다운로드.

한 검사가 자료 미확보로 실행되지 않아도 전체 요청을 단순 오류 화면으로 끝내지 않습니다. 검토 원인·필요한 자료·후속 절차를 출력하고 독립 검사는 계속합니다. 계산하지 않은 숫자는 미실행으로 표시하며 0이나 통과로 표시하지 않습니다.

## 기능별 화면 계약

| 페이지 | 필요한 입력 | 수행 내용 | 출력 |
|---|---|---|---|
| 데이터 준비 | SAP 파일·필드 매핑·회사/연도/원장 범위 | 형식·누락·중복·연결·변환 검증 | 정제 결과·오류 목록·검토조서 |
| JET | 검증 GL·선택적 로그·로그 기준 근거·규칙 조건 | GL 위험 후보, 기준 확인 후 로그 대사 | 규칙별 수행 내역·후보·대사 미실행 사유·조서 |
| 분석적 검토 | 비교 두 기간의 GL, 이후 TB·계정과목표 | 증감·추세, 지원 범위의 계산 | 비교표·분모 0/기간 누락 사유·조서 |
| KYC | 회사 선택·조회 기간·공시 유형·AI 선택 | 공시 수집·근거 검증·선택적 요약 | 출처·발췌 범위·요약·미확보/실패 사유·조서 |
| 자금 대사 | 은행 거래·현금 GL·계좌·통화·부호 매핑 | 유일 후보 대사·미연결 검토 | 연결/미연결·사유·조서 |
| 재고 | 수불·기초 수량·기준일·기준 | 기말 수량·미출고·음수 후보 | 품목별 결과·자료 미확보 사유·조서 |
| 조서/검토 이력 | 각 분석 결과·의견·증빙·검토자 | 결과와 판단 기록 정리 | Excel 및 CSV/Markdown 검토 초안 |

각 페이지는 무엇을 검사했는지, 무엇을 못 했는지와 이유를 함께 보여줍니다. 기본 검토조서는 검토요약·확인필요사항·검토대상·입력및조건으로 구성합니다. 서식의 검토 상태 입력은 자동으로 데이터 기준을 승인하거나 분석을 재실행하지 않습니다.

## 구현과 한계

Python 서비스의 execute_analysis/execute_batch와 기본 Excel 조서 생성기를 준비합니다. 웹 페이지·API·인증·승인 저장소·업로드·다운로드 라우트는 아직 구현 전입니다. 현재 Excel은 분석 실행 시점의 결과이며 원본이나 의견을 편집해도 Python 분석이 자동 갱신되지 않습니다. 검토 상태별 건수는 Excel 내부에서 계산합니다.

입력 읽기부터 execute_analysis 안에 넣으면 파일 누락도 검토 결과로 반환합니다. 파일 저장 자체의 실패, 서버 중단·메모리 부족 같은 장애에서는 산출물을 보장할 수 없으므로 웹 구현 시 별도 실패 알림·재시도/다운로드 복구가 필요합니다.

Excel 렌더러는 Artifact Tool JS를 사용하며, 호출 시 node_executable과 artifact_modules를 지정하거나 AUDIT_XLSX_NODE/AUDIT_XLSX_MODULES 환경변수로 설정합니다. 이 Codex 작업 환경의 번들 런타임으로 검증하며 실제 서버 배포 환경에는 렌더러 설치와 설정이 필요합니다. 렌더러가 없더라도 기존 CSV·Markdown 산출물은 사용 가능합니다.
