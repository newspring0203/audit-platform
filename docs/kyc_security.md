# KYC 회사 선택과 API 키 처리

## 회사 선택

회사명·종목코드 검색 → 후보 확인 → 8자리 DART 고유번호 선택 → 기간·유형별 공시 수집 순서로 진행합니다. 공시가 존재하는 OpenDART 등록 기업을 대상으로 하며 회사가 모호하면 후보 확인을 요청합니다.

```bash
python scripts/run_kyc.py --find-company 회사명일부
python scripts/run_kyc.py --company 선택한8자리DART고유번호
```

## 실행 환경별 키 전달

| 환경 | 키 처리 |
|---|---|
| 로컬 CLI·노트북 | Git 제외 `.env` 또는 서버 환경변수 |
| 공개 웹 | 방문자가 해당 KYC 실행에 본인 OpenDART 키 입력 |
| 분석 worker | 익명 표준입력 파이프로 전달하고 해당 작업 메모리에서 사용 |
| AI 요약 | 서버 OpenAI 설정과 `AUDIT_ALLOW_AI`로 활성화 |

브라우저 키 입력란은 실행 요청 시 비우고, 저장 대상은 키를 제외한 조건·공시·분석 결과입니다. 키가 포함된 요청 URL과 공급자 상세 오류는 사용자용 오류 코드로 처리합니다. 운영 키 관리는 접근권한·서비스 제공자 제한·교체 정책으로 구성합니다.

## 웹 처리

브라우저 → 인증·소유권 확인 → 키 형식·요청 한도 검사 → OpenDART 및 선택적 AI 호출 → 출처·문단·요약·검토 이슈 반환 순서입니다.

로컬은 개발용 Bearer, 공개 데모는 방문자 쿠키 세션을 사용합니다. API 요청·동시 분석·실행 시간·작업 만료를 관리하고, 외부 통신 대상은 공식 API로 제한합니다.
