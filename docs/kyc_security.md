# KYC 회사 선택과 API 키 보안

## 회사 선택

삼성전자는 연결 설명용 예시였으며 고정된 분석 대상이 아닙니다. 실행 도구와 노트북에는 기본 회사를 지정하지 않습니다.

회사명 일부·종목코드 검색 → 회사명·종목코드가 표시된 후보 목록 → 사용자가 DART 고유번호 선택 → 고유번호로 공시 수집.

지원 범위는 OpenDART에 등록되어 있고 요청 기간에 해당 공시가 있는 기업입니다. 모든 비상장 기업에 데이터가 있는 것은 아닙니다. 유사 회사가 여러 개면 첫 회사를 임의로 선택하지 않습니다.

```bash
python scripts/run_kyc.py --find-company 회사명일부
python scripts/run_kyc.py --company 선택한8자리DART고유번호
```

## API 키

키를 채팅·노트북·소스코드·프론트엔드 환경변수·브라우저 저장소에 넣지 않습니다. 로컬 개발은 .env, 운영 환경은 서버 환경변수 또는 비밀 저장소를 사용합니다. .env는 암호화된 금고가 아니라 접근권한을 제한한 로컬 설정 파일이며 Git에서 제외합니다.

현재 구현은 환경변수에서만 키를 읽고 키 값을 보고서·설정 출력에 포함하지 않습니다. OpenDART 요청 URL에는 인증키가 들어가므로 요청 URL과 서버 원문 오류를 로깅하지 않습니다. HTTP 오류와 인증 실패는 사용자용 오류 코드로 바꿉니다. OpenAI 키는 서버 HTTP Authorization 헤더에서만 사용합니다.

키는 서버에서 각 공식 API로 인증할 때만 전송됩니다. 키가 브라우저로 돌아가지 않습니다. 운영 키는 개발 키와 분리하고 서비스 제공자의 키 제한·접근 제한·회전 절차를 적용해야 합니다.

## 웹 연결 설계 — 아직 미구현

브라우저 → 백엔드 회사 검색/분석 요청 → 서버 키로 OpenDART·선택적 OpenAI 호출 → 공개 출처·요약·오류만 브라우저에 반환.

브라우저 요청에는 회사 고유번호·조회기간·AI 사용 여부만 포함합니다. 플랫폼 운영자의 API 키는 요청이나 응답에 넣지 않습니다. 공개 웹 배포 전에 사용자 인증, 요청별 권한, 사용량 제한, 동시 실행 제한과 비용 상한을 구현해야 합니다. AI는 기본 꺼짐입니다.

현재 FastAPI·프론트엔드·로그인·요청 제한을 실제로 구현한 상태는 아닙니다. 여기서 설명한 것은 그 구현의 요구사항입니다. 지금 준비한 기능은 Python 수집·요약과 명령행/노트북 실행입니다.
