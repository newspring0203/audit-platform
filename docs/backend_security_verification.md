# 비공개 작업 API 검증 기록

검증일: 2026-10-31. 새 audit-platform/.venv(Python 3.12)에서 전체 122개 테스트 통과. 백엔드 런타임의 설치 버전은 backend/requirements.lock.txt에 기록합니다.

## 확인한 동작

- 인증 없는 API 요청, 사용자 헤더 위조, 다른 사용자·다른 조직의 작업 조회/업로드/실행/삭제/다운로드 차단.
- 토큰 해시 저장, 만료·로그아웃 후 접근 거절, 작업별 비공개 파일 권한.
- 만료 시 즉시 접근 거절, 주기 삭제, 시작 시 삭제, 고아 임시 파일 정리, 삭제 실패 후 재시도.
- 실행 도중 삭제 및 시간 초과 시 자식 프로세스 종료, 삭제된 작업의 파일 재생성 방지.
- 인증된 소유자의 ZIP 다운로드, 무작위 artifact ID 거절, 응답 no-store 및 ETag/Last-Modified 미사용.
- 실제 업로드→분석 자식 프로세스→조서 ZIP 다운로드. 클렌징·JET·자금·재고와 입력 미제출 결과를 검증.
- API 요청의 AI 플래그만으로 서버의 유료 AI 비활성화 설정을 우회할 수 없음.
- 업로드 경로 조작·잘못된 형식·크기 초과·매크로·외부 링크·DTD/엔티티·압축 해제 용량 검사.
- 최소 이벤트에 원본 파일명·본문·토큰이 기록되지 않음.
- CSV의 수식 문자열 이스케이프, 원본 DataFrame 유지, 음수 금액 유지.
- Excel 렌더러 프로세스에 OpenDART/OpenAI 키가 전달되지 않음.

ASGI TestClient와 실제 로컬 분석 자식 프로세스를 사용했습니다. 실제 회사 자료나 운영 토큰을 만들지 않았고 OpenDART/OpenAI 실시간 호출도 하지 않았습니다. 앞서 작성한 분석·ADS 변환·KYC 모의 연결 테스트도 함께 실행했습니다.

## 미검증 또는 미구현 범위

브라우저 화면·SSO/OIDC·조직 공유 권한·실제 TLS 프록시·CDN·클라우드 객체 저장소·암호화/KMS·백업 삭제·분산 다중 worker·컨테이너 자원/네트워크 격리·침투 테스트·대규모 부하 테스트는 범위 밖입니다. 기본 개발 토큰은 공개 배포용 계정 관리가 아닙니다.

서버가 꺼지면 주기 정리도 멈춥니다. 재시작 시 정리하지만, 운영에서는 독립 정리 스케줄러·삭제 실패 경보·보존 정책 검토가 필요합니다. OS 파일 삭제와 SQLite secure_delete는 SSD·스냅샷·백업 전체의 물리적 보안 소거를 보증하지 않습니다.

현재 API 작업의 .runtime에만 만료 정책을 적용합니다. 이전 노트북·CLI의 data/raw 및 outputs는 자동 삭제하지 않습니다. no-store는 HTTP 캐시 저장을 금지하는 지시이며 이미 다운로드한 파일이나 외부 시스템의 복사본 회수를 보장하지 않습니다.
