# 프로젝트 구조와 개발 순서

## 데이터 흐름

웹 화면 → FastAPI → Python 분석 함수 → 검증 및 분석 결과 → 웹 화면

학습 단계에서는 Jupyter 노트북에서 같은 Python 함수를 직접 호출합니다.

## 책임

- `notebooks/`: 예제 데이터 확인과 단계별 학습.
- `src/audit_data_lab/`: SAP 입력 해석, ADS 변환, 데이터 검증, JET 분석.
- `backend/`: 요청 처리 및 분석 함수 호출.
- `frontend/`: 업로드, 분석 조건 입력, 결과 표시.
- `data/raw/sap/`: 로컬 학습용 원본 데이터 보관.
- `outputs/`: 로컬 변환 결과 및 검증 결과 보관.

## 첫 구현 범위

SAP 원본 컬럼 확인 → ADS 필드 매핑 → GL 변환 및 검증 → TB 변환 및 검증 → GL–TB 대사.

Python 기능을 검증한 후 API와 웹 화면을 연결합니다. 웹 업로드 파일의 저장·삭제 및 동시 실행 처리는 API 구현 단계에서 정합니다.
