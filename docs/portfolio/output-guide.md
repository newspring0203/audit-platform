## 주요 기능

- **QuickBooks:** 계정 제목·합계를 분리하고 거래마다 계정 정보를 붙이는 과정.
- **JET:** 선정 이유를 분개·전표 단위로 확인하고 로그 대사 상태를 함께 읽는 방법.
- **분석적 검토:** 기간별 거래 집계, 기말잔액 비교, 재무지표의 연결.
- **자금 대사:** 유일 후보·중복 후보·미대사를 나누는 방식.

## 파일 보관·출처

2026-11-01에 제공된 입력·출력 21개를 원본 바이트 그대로 복사했습니다. 공시 기반 자료·학습 예제·합성 자료가 함께 있으며 각 기능의 자료 출처를 구분해 표시합니다. 설명용 주석·서식·표시 변경이 포함될 수 있습니다. 이번 사본은 제공된 파일과 동일한 바이트로 보관했습니다.

일부 파일은 입력 오류·부분 수행 사례입니다. 정상 결과와 함께 예외처리의 동작을 확인할 수 있도록 상태를 표시했습니다. 재현에는 실행 조건과 원본 버전을 함께 사용합니다.

파일별 SHA-256·크기·원래 파일명은 [파일 목록](artifact-manifest.json)에 기록했습니다. 공개 업로드 전 사용자 식별값·문서 속성·설명 메모·자료 출처와 공개 가능 범위를 검토합니다. 현재 구성은 로컬 검토용입니다.

CSV는 UTF-8로 열고 계정·전표·접수번호 등 식별자는 텍스트로 가져옵니다. 날짜 일련번호·기간·부호는 각 데이터 사전을 기준으로 해석합니다. 결과 ID와 원본 거래키는 구분합니다.
