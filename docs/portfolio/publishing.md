# 공개 주소와 제출 버전 연결

- GitHub: https://github.com/newspring0203/audit-platform
- 웹 데모: https://audit-platform-ow3x.onrender.com

실제 HTTPS 주소에서 가상 예제 파일 직접 업로드·파일 분석 10종 실행·ZIP 조서 다운로드·방문자 격리·로그아웃·OpenDART 키 입력 검증을 검증했다. 결과는 [배포 검증 기록](../deployment-verification.json)에 있다. 배포 환경과 저장 정책은 [배포 안내](../deployment.md)에 정리했다.

README는 사용자가 직접 작성하기로 하여 공개 저장소에서 제거했다. report_commit은 최종 제출 버전이 확정될 때 지정한다. 시연 영상은 제작 후 등록한다.

KYC는 본인 인증키 입력과 비저장 경로를 검증했으며, 유효한 방문자 키로 실제 OpenDART 조회 성공까지 확인한 기록은 아니다.
