# 공개 주소와 제출 버전 연결

- GitHub: https://github.com/newspring0203/audit-platform
- 웹 데모: https://audit-platform-ow3x.onrender.com

실제 HTTPS 주소에서 합성 분석 9종 실행·ZIP 조서 다운로드·방문자 격리·로그아웃·외부 요청 및 업로드 차단을 검증했다. 결과는 [배포 검증 기록](../deployment-verification.json)에 있다. 배포 환경과 저장 정책은 [배포 안내](../deployment.md)에 정리했다.

README는 사용자가 직접 작성하기로 하여 공개 저장소에서 제거했다. report_commit은 최종 제출 버전이 확정될 때 지정한다. 시연 영상은 제작 후 등록한다.
