# 시연 영상 구성: 3~4분

합성 자료를 중심으로 구성한 촬영용 시나리오다. [시연 영상](https://www.youtube.com/watch?v=LWEW0ocwOVs)

| 시간 | 화면 | 설명 |
|---|---|---|
| 0:00–0:20 | 플랫폼과 왼쪽 메뉴 | 반복 분석과 근거 확인을 연결하는 로컬 감사 지원 MVP 소개 |
| 0:20–0:50 | 분석적 검토 → 자료 준비 | 연도 조건 입력, 합성 GL 업로드, 자료 버전·PBC 참조 설명 |
| 0:50–1:30 | 분석 결과 탭 | 요약 카드·전년 비교·증감 후보 설명. 차트는 현재 페이지의 항목별 비교임을 언급 |
| 1:30–2:10 | 결과 행 → 검토 기록 | 원본 행·자료 버전·산식·조건 확인. 사용자 검토 필요성 설명 |
| 2:10–2:40 | 검토 기록 저장 | 증빙 참조·설명·결론 입력 및 이력 저장 |
| 2:40–3:10 | 조서 다운로드 | 분석 ZIP과 이후 검토 이력 파일을 구분해 설명 |
| 3:10–3:40 | 보조 기능 또는 마무리 | 사용자별 GL 분할/QuickBooks 평탄화 중 하나만 짧게 보여주고 구현 한계·후속 계획 정리 |

## 시작 내레이션 초안

“감사 분석에서는 이상 거래를 찾는 것뿐 아니라, 어떤 자료와 조건으로 나온 결과인지 확인하고 검토 근거를 남기는 과정이 중요합니다. 이 프로젝트는 데이터 분석부터 원본 확인, 검토 기록과 조서 다운로드까지 연결한 로컬 MVP입니다.”

## 끝 내레이션 초안

“합성 자료와 자동화 테스트로 처리 흐름을 검증하고 SAP 전처리를 웹에 연결했습니다. 앞으로 실제 파일 형식과 역할별 검토 기능을 확장할 계획입니다.”

녹화 전 준비: 1080p 화면·브라우저 확대율 고정, 합성 GL·조건 준비, 토큰 입력을 마친 뒤 연결 설정 접기. 촬영은 키 입력 영역을 접고 공개용 자료 화면을 중심으로 구성한다. 공개 영상과 GitHub 링크를 보고서에 연결한다.
