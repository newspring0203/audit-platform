# SAP–ADS 전처리 테스트

프로젝트의 pandas·openpyxl·IPython 설치 환경에서 실행합니다.

```bash
python -m unittest discover -s tests -p 'test_*.py' -v
```

작은 가상 데이터의 정답 잔액, 오류 입력 거절, 차대변 불균형과 GL–TB 차이 보고, 실제 SAP 예제의 전체 변환을 확인합니다. 분석 로직을 테스트에 복제하지 않고 노트북의 실제 코드 셀을 실행합니다. 모든 테스트 결과 파일은 임시 폴더에 생성되며 기존 CSV 및 SAP 원본을 변경하지 않습니다.

통화의 영문 3자리 형식 검사는 ISO 4217 목록 검증을 대신하지 않습니다. 특별기간 검사는 이 프로젝트의 달력연도 가정을 따르며, 비달력 회계연도는 지원하지 않습니다.
