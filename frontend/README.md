# Audit Platform - Frontend

회계감사 데이터 분석 과정을 웹 브라우저에서 실행하고, 분석 결과와 원본 근거를 확인할 수 있도록 구현한 사용자 인터페이스입니다.

HTML, CSS, JavaScript를 사용하였으며, FastAPI가 정적 파일과 분석 API를 제공합니다. 별도의 Node.js 또는 npm 설치 없이 실행할 수 있습니다.

## 1. 주요 기능

| 기능           | 설명                                       |
| -------------- | ------------------------------------------ |
| 작업 관리      | 분석 작업 생성 및 기존 작업 조회           |
| 데이터 업로드  | 감사 분석에 필요한 원본 자료 등록          |
| 분석 조건 설정 | 기능별 분석 조건 및 비교 기간 지정         |
| 자료 관리      | PBC 참조, 자료 기간, 이전 버전 비교        |
| 감사 분석 실행 | 입력 조건을 백엔드 Python 분석 엔진에 전달 |
| 결과 시각화    | 분석 결과표, 요약 카드, 비교 막대 표시     |
| 원본 추적      | 결과에 연결된 원본 행과 계산 정의 확인     |
| 검토 기록      | 검토 의견, 기준서 수동 참조, 이력 관리     |
| 결과 다운로드  | 분석 결과 및 감사조서 파일 다운로드        |

## 2. 사용자 작업 흐름

작업 생성 → 자료 업로드 → 분석 조건 설정 → 분석 실행 → 결과 검토 → 원본 확인 → 조서 다운로드

사용자가 입력한 조건과 업로드한 자료를 FastAPI 백엔드로 전달하고, Python 분석 엔진의 결과를 표시합니다.

분석 결과를 확인하는 과정에서는 계산 결과, 원본 자료, 적용 조건, 검토 기록을 조회할 수 있습니다.

## 3. 프로젝트 구조

| 파일               | 역할                                                     |
| ------------------ | -------------------------------------------------------- |
| `index.html`       | 웹페이지 구조, 버튼, 입력창, 결과 표시 영역              |
| `workspace.css`    | 색상, 레이아웃, 버튼 스타일 등 디자인                    |
| `workspace.js`     | 버튼 클릭, 파일 업로드, API 호출, 결과 표시 등 화면 동작 |
| `core/session.mjs` | 로그인 토큰, 세션 상태, 인증 API 요청 관리               |
| `chevron.svg`      | 화면에 사용하는 SVG 이미지                               |
