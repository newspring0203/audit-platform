# Audit Platform · Frontend

감사 자료 업로드부터 분석 결과 확인, 원본 추적, 검토 조서 다운로드까지 제공하는 브라우저 화면입니다. 상단 제목은 **Audit Analytics Workspace**입니다.

**[배포 사이트](https://audit-platform-ow3x.onrender.com/)** · [백엔드 안내](../backend/README.md) · [배포 설정](../docs/deployment.md)

## 배포 사이트 이용

1. **데모 시작**을 눌러 방문자 전용 작업 공간에 연결합니다. 토큰을 직접 입력할 필요가 없습니다.
2. 기능을 선택하고 분석 조건을 입력한 뒤 **분석 작업 만들기**를 누릅니다.
3. 해당 기능에 맞는 CSV·TXT·XLSX 자료를 업로드합니다. 파일과 자료 설명은 자동 저장됩니다.
4. **분석 실행** 후 결과표·계산 조건·연결된 원본 행을 확인합니다.
5. 검토 기록을 작성하고 **분석 조서 ZIP** 또는 **최신 검토 이력**을 내려받습니다.

SAP 전처리, QuickBooks 전처리, 입력 사용자별 GL 분할, 데이터 클렌징, JET, 분석적 검토, 자금 대사, 재고 분석, 매출채권·금융기관 조회 회신 비교, KYC 공시 메뉴를 제공합니다. 분석 조건과 파일은 사용자가 직접 입력합니다. 제공된 예제 자료는 선택적으로 사용할 수 있으며 서버가 자료나 조건을 강제로 대입하지 않습니다.

SAP 전처리에는 BSEG·BKPF·GLT0 입력과 회사·회계연도 등 조건이 필요합니다. 필요한 컬럼과 빈 CSV 서식은 자료 업로드 영역에서 확인할 수 있습니다. TXT의 구분자 등 기능별 형식은 화면 안내를 따릅니다.

## KYC와 본인 OpenDART 인증키

KYC 공시 작업은 파일 대신 회사·조회 기간·보고서 종류를 입력합니다. 작업을 만든 뒤 본인이 [금융감독원 OpenDART에서 발급받은 인증키](https://opendart.fss.or.kr/uss/umt/EgovMberInsertView.do)를 암호 입력란에 입력하고 실행합니다.

키는 일반 분석 조건과 분리되어 해당 실행 요청 본문으로만 전달됩니다. 입력란은 실행 요청 시 비워지며 localStorage·sessionStorage·쿠키에 키를 저장하지 않습니다. 서버가 키를 일시적으로 받아 OpenDART 조회에 사용하므로 HTTPS 주소에서 이용해야 합니다. 서버 내부 처리 범위와 검증은 [백엔드 안내](../backend/README.md#방문자-opendart-키-처리)를 참고합니다.

AI 요약은 별도 서버 설정과 OpenAI 자격증명이 필요한 선택 기능입니다. 공개 서버에서 활성화하지 않으면 공시 수집과 원문 검토만 수행할 수 있습니다. OpenDART 키 입력이 AI 사용 권한을 의미하지는 않습니다.

## 세션과 자료 보관

방문자별 작업은 분리됩니다. 세션은 시작 후 1시간, 작업 자료는 생성 후 기본 1시간에 접근이 만료됩니다. 서버 실행 중 정리 작업이 만료 자료를 삭제합니다. 무료 서버의 휴면·재시작·재배포 시 더 일찍 사라질 수 있으므로 필요한 결과는 다운로드합니다.

처리 권한이 있는 자료만 업로드하고 개인정보·비밀정보 포함 여부를 확인합니다. 키를 파일·자료 메모·검토 기록에 입력하지 않습니다. 계정 기반 영구 보관이나 기업용 SSO는 제공하지 않습니다.

## 로컬 실행

저장소 루트에서 실행합니다.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-deploy.txt
.venv/bin/python scripts/run_local.py
```

`http://127.0.0.1:8000`에서 개발용 연결 설정을 열고 `.runtime/reviewer.token`을 로컬 편집기로 확인해 입력합니다. 로컬 토큰을 GitHub·채팅에 게시하지 않습니다. 별도의 npm 빌드는 필요하지 않습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조, 공개 안내, 입력·결과·검토 영역 |
| `workspace.css` | 화면 스타일과 반응형 배치 |
| `workspace.js` | 기능 선택, 사용자 조건·파일 업로드, 분석·다운로드, 일회성 DART 키 입력 |
| `core/session.mjs` | 방문자 쿠키/로컬 토큰 인증, 요청 취소, 세션 변경 처리 |

세션 동작 검증은 저장소 루트에서 `node --test tests/frontend_session.test.mjs`로 실행합니다. 서버 측 업로드·소유권·키 처리 검증은 Python 테스트에서 수행합니다.
